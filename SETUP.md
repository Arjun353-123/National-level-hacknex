# 🚀 Quick Setup Guide

## Install & Run (2 commands)

```bash
# 1. Install dependencies
npm install

# 2. Start development server
npm run dev
```

## 🌐 Access the Application

Open your browser and go to: **http://localhost:3000**

## 🔐 Test Login

**Admin:** `admin@hospital.com` (any password)  
**Patient:** `patient@email.com` (any password)

## ✨ Features to Try

1. **3D Cursor** - Move your mouse around
2. **Glowing Buttons** - Hover over buttons
3. **AI Chatbot** - Click floating button (bottom right)
4. **Image Upload** - Upload and analyze medical images (patient dashboard)
5. **Admin Panel** - View patient management (admin dashboard)

Enjoy exploring the platform! 🎉
